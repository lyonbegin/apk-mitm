# M330 Pro 학교 공용부 디지털 트윈 — 가상 평면도 v0.4

## 지도 대상
- 등촌고등학교의 **가상** 건물 구조: 면학동·경애동 각 1~5층 (총 10개 층)
- 지도에 포함: 서측·중앙·동측 복도, 층별 공용 홀, 승강기 앞 공용부, 서측·동측 계단실(계단 단차 포함), 1층 정문 출입구 공용부
- 지도에서 제외: 교실, 교무실, 행정실, 개별 사무실, 기타 실내 공간
- 임의로 생성한 가상 지도이며 실제 학교의 도면·거리·통로 폭을 측량하거나 검증한 자료는 아님

## 계단
- 계단실은 매 층에 서측과 동측 2개소로 표시합니다. 계단은 공용부 청소 대상에서 빠지지 않습니다.
- **계단 단차는 로봇 주행 대상에서 제외**하며, 수동 청소 완료/미완료를 지도와 DB에 표시합니다.
- 수동 청소: `POST /api/twin/manual` `{floor_id,zone_id,action:"complete"|"reset"}`.
- M330 Pro의 계단 오르기·내려가기 또는 단차 안전주행 기능이 검증되지 않았으므로, 별도 실기기 검증 없이 로봇 청소 완료로 표시하지 않습니다.

## 복도/공용부 가상 로봇 청소
- 청소 가능 구역: 각 층의 복도 3구역, 공용 홀, 승강기 앞 공용부, 1층 출입구 공용부.
- 로봇을 해당 층에 수동 배치 후 구역을 선택하여 청소 시작/일시정지/재개/중지/초기화를 시뮬레이션할 수 있습니다.
- 사각형 구역의 지그재그 경로를 생성하고 시간 경과에 따라 좌표·가상 배터리·진행률을 계산하여 2D SVG 지도에 표시합니다.
- 서로 다른 로봇의 동일 구역 중복 청소를 시작하지 않도록 서버에서 검증합니다.
- 시간 경과 시 자동으로 가상 완료 처리하지만 실제 장치 명령은 송신하지 않습니다.

## API
- `GET /api/twin/floors` : 전체 층 목록
- `GET /api/twin/map?floor_id=myeonhak-5` : 공용부·계단·로봇 주행 가능 구역 지도 정의
- `GET /api/twin/state?floor_id=myeonhak-5` : 가상 로봇 작업 좌표·진행률·계단 청소 상태
- `POST /api/twin/command` : `robot_id`, `floor_id`, `zone_id`, `action`(start/pause/resume/stop/reset)
- `POST /api/twin/manual` : 계단 수동 청소 완료/취소

## 데이터 보존
- 기존 로봇·일정·이벤트 DB 테이블을 유지하고, 신규 `twin_runs`, `twin_manual`을 생성합니다.
- 계단 청소 상태는 브라우저 세션·건물·층·구역 단위로 구분하여 SQLite 영구 볼륨에 저장합니다.
- 기존 실제 기기 LAN 브리지는 읽기 전용으로 유지합니다.

## 검증
GitHub Actions `m330-web-smoke.yml` 및 `m330-browser-smoke.yml`에서 API와 모바일 SVG 지도를 검증합니다. 실제 학교와의 일치 여부 및 실기기 계단 청소 기능은 별개의 검증 대상입니다.
